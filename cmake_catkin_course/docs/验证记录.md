# 简单 Demo 验证记录

验证日期：2026-10-20。

环境：WSL Ubuntu 20.04、G++ 10.5、GNU Make 4.2、CMake 3.16、ROS 1 Noetic。

- 单文件程序输出 `3`。
- 多文件一次性编译与分步编译均输出 `3`。
- 漏掉 `add.o` 时链接按预期失败，补齐后恢复。
- Make 无改动时无需重编；修改 `add.cpp` 时只重编对应对象；修改 `add.h` 时重编两个对象。
- 三行 CMake 配置可正常构建，程序输出 `3`。
- catkin 可构建单个 `add_demo` 包。
- `add_node` 实际发布 `/lesson2/sum`，收到 `data: 3`。

复现命令为课程根目录下的 `bash scripts/verify_cpp.sh` 和 `bash scripts/verify_ros.sh`。验证使用临时目录，结束后清理自己启动的进程。
